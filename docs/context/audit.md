# Реестр базового аудита

Актуализировано: 2026-10-16. Источник: [yukiwire-audit.md](../../yukiwire-audit.md), ревизия `5fea661`. Исходные номера 1–22 сохранены, исходник аудита не изменён. Результаты текущего дерева и публикации — в [state.md](state.md).

«Закрыт» означает подтверждённое исправление в указанном объёме. «На проверке» означает реализованный код с незавершённой приёмкой; это не обещание работы реального TUN/WFP. Mocks, проверка конфигурации Xray и HTTP-ответ страницы не доказывают видео или корректность системных фильтров.

## Остаток для повторного аудита

Приоритет — настоящие IPC/UAC и граница привилегий, затем WFP и TUN+system proxy: авария ядра/helper/host, IPv4/IPv6/DNS, восстановление и YouTube-видео. Старый активный клиент пользователя/zapret не останавливались. На машине была установлена промежуточная защищённая версия; после неё helper изменился, поэтому её проверка не подтверждает текущую версию.

Общий HTTP WinInet без auth, отсутствие собственной подписи, ручная установка обновлений, legacy recovery старым клиентом и отсутствие автоматического удаления старых protected versions — явные ограничения. Не скрывать их под формулировкой «аудит полностью закрыт». Детали решений: [decisions.md](decisions.md); воспроизводимые команды и внешние эффекты: [testing.md](testing.md).
