## Реализованный объём

- Повышенный Python исключён из production. UI/Python остаются обычными, native helper/Xray/Wintun устанавливаются отдельно в защищённый Program Files. Ограниченные IPC/policy, проверка ACL/владельца/хэшей, Job Object, защищённый журнал. Старый worker есть только в test host. Подробнее D-007; живая приёмка открыта.
- Случайные endpoints с auth SOCKS/probe/metrics; pure TUN без обычных прокси, combined сохраняет HTTP для WinInet. Общий HTTP без auth остаётся ограничением для локальных процессов. Метрики читаются HTTP, без statsquery subprocess.
- Опциональный persistent WFP kill switch для system/TUN: journal-before-arm, удержание блокировки при аварии/reconnect, явное снятие даже без ядра. По умолчанию выключен. Реальные WFP-фильтры не включались, D-010 содержит ограничения.
- Раздельный direct/VPN DNS, HTTPS-подписки с атомарным DPAPI-хранением, локальный QR, отдельные HTTPS-замеры профилей, перенос JSON через native host, добровольный ограниченный технический журнал без raw stderr/секретов.
- Парсер понимает дополнительные метаданные/HTTPUpgrade/REALITY, Hysteria2+Salamander, базовый KCP, userspace WireGuard JSON. Удалённый ядром H2, неработающий legacy KCP seed и отключение TLS-проверки отвергаются явно.
- Сериализация переходов, поколения и независимые cancel Events; поздние события не запускают новое соединение. Session/validator вынесены в session.py, dispatcher — именованные handlers. Подписки/замеры не держат lock состояния во время сети.
- Обновление/откат правил при активной сессии, immutable CDN fallback, закреплённый bundled RU snapshot с ru-blocked. Сборка не перезаписывает source runtime/core geodata.
- Независимый SHA256 Xray, ручная проверка обновлений, единая версия, production без test hooks. Release собирает/проверяет артефакт того же запуска, проверяет точный набор/хэши; Actions закреплены SHA.
- Setup содержит полный подписанный offline WebView2 x64; .NET 4.8 требуется заранее. Отдельная тестовая регистрация/mutex установщика не затрагивает активную установку пользователя.

## Открытая приёмка и ограничения

В `verify_network_component.py --install` установлена промежуточная версия `4d09a851d161587767a5ecc9af3d4424`, её read-only ACL/owner/hash проверка прошла. Второй UAC для helper остался без ответа, завершён только собственный Python теста. **IPC/prepare/stop/EOF не завершены.** С тех пор helper изменился: установленная версия не подтверждает текущее дерево. Не повторять интерактивный UAC, когда пользователь недоступен.

Настоящие TUN/system/combined, новая граница привилегий, WFP IPv4/IPv6/DNS/старые соединения/BFE/reboot/recovery, миграция legacy lease, native диалоги переноса и чистая offline-машина без WebView2 требуют приёмки. Protected versions пока не удаляются автоматически. При legacy TUN-журнале нужно завершить восстановление старым клиентом.

Активная установленная программа пользователя и zapret не останавливались. Совместный режим TUN+system proxy остаётся обязательным: браузеры через WinInet, прочий TCP/UDP через TUN, общий recovery и сохранение чужих proxy-настроек. Исторически чистый TUN с определённым zapret давал YouTube TLS-ошибки; прокси обходил этот путь. HTTP-ответ страницы не доказывает длительное видео. Новый код не прошёл живую проверку этого сценария.
