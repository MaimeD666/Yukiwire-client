The portable build includes unchanged Xray, Wintun, WebView2 SDK binaries and official Python executables/DLLs. The Python standard-library ZIP is filtered to exclude developer packages/tests. No PyInstaller bootloader, Tk/Tcl, Node or Electron runtime is distributed. WebView2 Runtime is a shared Microsoft Windows prerequisite under its own terms; Setup invokes the bundled official offline installer only when the Runtime is absent. OpenSSL version is recorded in portable.json (3.5.9 in the default Python 3.14.8 runtime); the PSF notice bundle also includes upstream library acknowledgements. Yukiwire and its installer are unsigned.

The geometric application icon is generated from the project's own source in native/IconBuilder.cs; its SVG counterpart is in ui/assets/icon.svg.

The vendored jsQR file has SHA256 `bc40c8a15196236b2314db0856f72ca0b49980cd5413b8c852a7349f5fee0859` (official npm jsqr 1.4.0 package SHA256 `b5299b37917a1fe7a8cab9dd5cc6b8accf82663add80abe5bf7761a921cc6602`). QR images and decoded profiles are processed locally. The QR fixture in tests contains only the public synthetic documentation address `192.0.2.1` and a synthetic UUID.
