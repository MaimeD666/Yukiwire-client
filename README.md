# Yukiwire

Я собиралась спать, но меня заставили написать README. Ладно. (－_－) zzz

Клиент Xray для **Windows 10/11 x64**. VLESS, VMess, Trojan, Shadowsocks и JSON Xray. Есть TUN, системный прокси, локальный прокси и маршруты для РФ.

## Забрать

[Скачать](https://github.com/MaimeD666/Yukiwire-client/releases) — установщик или portable ZIP. Я всё упаковала.

Установи или распакуй, добавь свою ссылку подключения, нажми «Подключиться». Сервер нужен свой, из воздуха я его не достану.

## Поковырять

Нужен Python 3.11+ x64. В клонированном репозитории:

```powershell
python scripts/download_core.py
python scripts/download_wintun.py
python -m yukiwire
```

Интерфейс — `ui/`, сеть — `yukiwire/`, окно Windows — `native/`.
Для сборки: `python scripts/build_portable.py`, затем `python scripts/build_installer.py`.

## Игровой режим

В разделе «Маршруты» включите «Игры без VPN», выберите Dota 2, Counter-Strike 2 или свой `.exe` игры и сохраните маршруты. Для перехвата всего трафика, включая UDP, выберите TUN в настройках подключения. После применения изменений перезапустите игру.

Выбранные процессы подключаются напрямую, остальные приложения сохраняют текущие маршруты VPN. Блокировки имеют приоритет над игровыми исключениями. Указывайте имя процесса или полный путь с точным регистром букв; лаунчер добавлять не нужно. Отключение режима сохраняет список игр. В режиме «Правила JSON» игровые исключения не применяются. В локальном и системном прокси они действуют только на трафик, поступивший в Yukiwire.

Форки и PR приветствуются. Если сделал что-то прикольное, покажи. Ради этого я, пожалуй, проснусь.

## Маршруты и применение изменений

«Все, кроме РФ» направляет российские сайты напрямую, остальные — через VPN. Способ определения РФ выбирается здесь же: по доменам или по доменам и IP. «Все сайты» направляет интернет через VPN, «По списку» — только заблокированные и ваши выбранные сайты. Локальная сеть доступна напрямую, если для неё нет явного исключения.

Исключения «Через VPN», «Без VPN» и «Блокировать» меняют основной маршрут. При совпадении первым срабатывает правило в порядке: блокировка → игры без VPN → сайты через VPN → сайты без VPN → основной маршрут. Правила из исходного JSON настраиваются в самом профиле.

Маршруты и настройки можно сохранять при включённом VPN. В настройках включите «Переподключаться после изменений», чтобы применять их сразу после сохранения. По умолчанию тумблер выключен: изменения ждут следующего подключения, что видно у кнопки сохранения. Переключатель «Восстанавливать при обрыве» независимо управляет восстановлением потерянной связи. Обновление файлов списков выполняется при выключенном VPN.

## TUN и браузер

В настройках подключения для TUN можно включить «Системный прокси вместе с TUN». Браузеры и программы, учитывающие прокси Windows, используют локальный HTTP-прокси Yukiwire; остальные соединения, включая UDP игр, продолжают идти через TUN. Правила маршрутов общие для обоих способов подключения. При отключении или сбое восстанавливаются исходные настройки прокси и собственные изменения TUN.

Это сочетание полезно, если сайт работает через прокси, но его HTTPS-соединение ломается при совместной работе TUN и сетевого фильтра. Для YouTube через VPN уберите `youtube.com` из «Без VPN» и при необходимости добавьте в «Через VPN» домены `youtube.com`, `googlevideo.com`, `ytimg.com`, `youtubei.googleapis.com`, `yt3.ggpht.com`, `yt4.ggpht.com`. Поддомены учитываются. Настройки zapret приложение не изменяет. «Проверить сайты» продолжает отдельно выявлять проблемы самого TUN: совместный режим не исправляет обработку TCP в его сетевом стеке.
