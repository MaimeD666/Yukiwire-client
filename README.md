# Yukiwire

Я собиралась спать, но меня заставили написать README. Ладно. (－_－) zzz

Клиент Xray для **Windows 10/11 x64**. VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и JSON Xray (включая WireGuard в userspace). Есть TUN, системный прокси, локальный прокси и маршруты для РФ.

В исходниках идут исправления [аудита](docs/context/audit.md). Новая привилегированная сетевая часть и kill switch ещё требуют живой приёмки на Windows; готовый релиз с этими изменениями пока не опубликован. Проверенные сценарии и ограничения перечислены в [состоянии проекта](docs/context/state.md).

## Забрать

[Скачать](https://github.com/MaimeD666/Yukiwire-client/releases) — установщик или portable ZIP. Я всё упаковала.

Установи или распакуй, добавь свою ссылку подключения, нажми «Подключиться». Сервер нужен свой, из воздуха я его не достану.

## Поковырять

Нужен Python 3.11+ x64. В клонированном репозитории:

```powershell
python scripts/download_core.py
python scripts/download_wintun.py
python -m yukiwire
```

Интерфейс — `ui/`, сеть — `yukiwire/`, окно Windows — `native/`.
Для сборки: `python scripts/build_portable.py`, затем `python scripts/build_installer.py`.

Для запуска нужны .NET Framework 4.8 и WebView2 Runtime. Установщик включает полный WebView2 x64 и устанавливает его без загрузки из интернета, если Runtime отсутствует; .NET 4.8 следует установить заранее. Portable использует уже установленный WebView2. Сборка поставляет embedded Python 3.14.8 и готовые RU-списки; Python 3.11 — минимальная среда разработки и отдельная версия CI.

## Игровой режим

В разделе «Маршруты» включите «Игры без VPN», выберите Dota 2, Counter-Strike 2 или свой `.exe` игры и сохраните маршруты. Для перехвата всего трафика, включая UDP, выберите TUN в настройках подключения. После применения изменений перезапустите игру.

Выбранные процессы подключаются напрямую, остальные приложения сохраняют текущие маршруты VPN. Блокировки имеют приоритет над игровыми исключениями. Указывайте имя процесса или полный путь с точным регистром букв; лаунчер добавлять не нужно. Отключение режима сохраняет список игр. В режиме «Правила JSON» игровые исключения не применяются. В локальном и системном прокси они действуют только на трафик, поступивший в Yukiwire.

## Маршруты и применение изменений

«Все, кроме РФ» направляет российские сайты напрямую, остальные — через VPN. Способ определения РФ выбирается здесь же: по доменам или по доменам и IP. «Все сайты» направляет интернет через VPN, «По списку» — только заблокированные и ваши выбранные сайты. Локальная сеть доступна напрямую, если для неё нет явного исключения.

Исключения «Через VPN», «Без VPN» и «Блокировать» меняют основной маршрут. При совпадении первым срабатывает правило в порядке: блокировка → игры без VPN → сайты через VPN → сайты без VPN → основной маршрут. Правила из исходного JSON настраиваются в самом профиле.

Маршруты и настройки можно сохранять при включённом VPN. В настройках включите «Переподключаться после изменений», чтобы применять их сразу после сохранения. По умолчанию тумблер выключен: изменения ждут следующего подключения, что видно у кнопки сохранения. Переключатель «Восстанавливать при обрыве» независимо управляет восстановлением потерянной связи. Списки можно обновлять через активное подключение; новая версия применяется при следующем подключении, прежняя доступна для отката.

## TUN и браузер

В настройках подключения для TUN можно включить «Системный прокси вместе с TUN». Браузеры и программы, учитывающие прокси Windows, используют локальный HTTP-прокси Yukiwire; остальные соединения, включая UDP игр, продолжают идти через TUN. Правила маршрутов общие для обоих способов подключения. При отключении или сбое восстанавливаются исходные настройки прокси и собственные изменения TUN.

Это сочетание полезно, если сайт работает через прокси, но его HTTPS-соединение ломается при совместной работе TUN и сетевого фильтра. Для YouTube через VPN уберите `youtube.com` из «Без VPN» и при необходимости добавьте в «Через VPN» домены `youtube.com`, `googlevideo.com`, `ytimg.com`, `youtubei.googleapis.com`, `yt3.ggpht.com`, `yt4.ggpht.com`. Поддомены учитываются. Настройки zapret приложение не изменяет. «Проверить сайты» продолжает отдельно выявлять проблемы самого TUN: совместный режим не исправляет обработку TCP в его сетевом стеке.

## Профили, DNS и диагностика

В профилях доступны HTTPS-подписки, QR из локального изображения, сравнение HTTPS-задержки и сортировка. Задержка измеряется через профиль и текущую сеть; активный VPN влияет на результат. Удаление подписки сохраняет её профили как обычные. Экспорт JSON позволяет перенести профили на другой ПК, но содержит открытые ключи подключения: храните файл как пароль. Адрес подписки остаётся в локальном DPAPI-хранилище и в экспорт профилей не входит.

В TUN DNS может следовать доменным маршрутам: direct-домены — через системный или заданный IP-резолвер, VPN-домены — через выбранный DoH. Можно отправить все DNS-запросы через VPN. Общий DNS Windows не позволяет определить, какая игра запросила имя. Матрица сайтов запускается по кнопке; домашняя страница браузера настраивается, по умолчанию пустая.

Технический журнал включается добровольно, ограничен 512 КиБ и содержит события, тайминги и категории ошибок без адресов серверов, ключей и сырых строк ядра. В настройках можно сохранить отчёт, очистить журнал и проверить новый релиз GitHub. Обновление приложения устанавливается вручную.

## Повышенные права и защита при обрыве

UI и Python работают от обычного пользователя. При первом TUN отдельный native-компонент устанавливается в защищённую папку Program Files; Windows запрашивает UAC для установки и отдельно для запуска компонента. Он переиспользуется до выхода из приложения. Код приложения и профили остаются portable/per-user. Бинарники Yukiwire не подписаны.

Переключатель «Блокировать интернет при обрыве» выключен по умолчанию. Он относится к TUN и системному прокси, требует native-компонента и блокирует обход ядра при сбое/переподключении. Прямые маршруты, обработанные ядром, сохраняются; приложения вне системного прокси и прямые LAN-соединения могут блокироваться. Локальная петля и DHCP остаются доступны. В локальном режиме переключатель не действует. Для WireGuard с этой защитой нужен IP endpoint.

Аварийное закрытие приложения сохраняет блокировку; нажмите «Снять блокировку» или выполните восстановление сети с UAC. Явное отключение/выход снимает её после остановки своей сессии. Это не гарантия защиты ранней загрузки Windows до запуска BFE. Старый TUN-журнал сначала восстанавливается прежней версией приложения; чужие сетевые настройки не удаляются. Защищённые версии компонента пока не удаляются автоматически при удалении основного клиента.
